= Modificare l'ordine di visualizzazione degli shelf in SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile modificare l'ordine dei ripiani visualizzati nella pagina Hardware per farlo corrispondere all'ordine fisico dei ripiani in un armadio.

.Passaggi
. Seleziona *Hardware*.
. Dall'angolo in alto a destra di una visualizzazione dello shelf, seleziona le frecce su o giù per riorganizzare l'ordine degli shelf mostrati nella pagina Hardware.

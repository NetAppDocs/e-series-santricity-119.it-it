= Configurare gli indirizzi del server NTP in SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile configurare una connessione al server NTP (Network Time Protocol) in modo che il controller interroghi periodicamente il server NTP per aggiornare il proprio orologio interno del tempo.

.Prima di iniziare
* È necessario installare e configurare un server NTP nella propria rete.
* È necessario conoscere l'indirizzo del server NTP primario e di un eventuale server NTP di backup. Questi indirizzi possono essere fully qualified domain name, indirizzi IPv4 o indirizzi IPv6.


[NOTE]
====
Se si immettono uno o più domain name per i server NTP, è necessario configurare anche un DNS server per risolvere l'indirizzo del server NTP. È necessario configurare il DNS server solo sui controller in cui è stato configurato NTP e fornito un domain name.

====
.Informazioni su questa attività
NTP consente all'array di storage di sincronizzare automaticamente gli orologi del controller con un host esterno utilizzando Simple Network Time Protocol (SNTP). Il controller interroga periodicamente il server NTP configurato e poi utilizza i risultati per aggiornare il proprio orologio interno. Se solo un controller ha NTP abilitato, il controller alternativo sincronizza periodicamente il proprio orologio con quello del controller che ha NTP abilitato. Se nessuno dei due controller ha NTP abilitato, i controller sincronizzano periodicamente i propri orologi tra loro.

[NOTE]
====
Non è necessario configurare NTP su entrambi i controller; tuttavia, farlo migliora la capacità dell'array di storage di rimanere sincronizzato durante guasti hardware o di comunicazione.

====
.Passaggi
. Seleziona *Hardware*.
. Se il grafico mostra le unità, fare clic sulla scheda *Controllers & Components*.
+
La grafica cambia per mostrare i controller anziché le unità.

. Fai clic sul controller che desideri configurare.
+
Viene visualizzato il menu contestuale del controller.

. Seleziona *Configura server NTP*.
+
Si apre la finestra di dialogo Configure Network Time Protocol (NTP) Server.

. Seleziona *Voglio abilitare NTP sul Controller* (*A* o *B*).
+
Ulteriori selezioni vengono visualizzate nella finestra di dialogo.

. Seleziona una delle seguenti opzioni:
+
** *Ottieni automaticamente gli indirizzi del server NTP dal server DHCP* -- Gli indirizzi del server NTP rilevati vengono visualizzati.
+
[NOTE]
====
Se l'array di archiviazione è configurato per utilizzare un indirizzo NTP statico, non vengono visualizzati server NTP.

====
** *Specificare manualmente gli indirizzi dei server NTP* -- Inserire l'indirizzo del server NTP primario e un indirizzo del server NTP di backup. Il server di backup è facoltativo. (Questi campi relativi agli indirizzi vengono visualizzati dopo aver selezionato il pulsante di opzione.) L'indirizzo del server può essere un fully qualified domain name, un indirizzo IPv4 o un indirizzo IPv6.


. *Facoltativo:* Inserire le informazioni del server e le credenziali per l'autenticazione per un server NTP di backup.
. Fare clic su *Save*.


.Risultati
La configurazione del server NTP viene visualizzata nelle impostazioni del controller, scheda *DNS / NTP*.

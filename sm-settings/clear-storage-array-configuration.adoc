= Cancella la configurazione dell'array di storage in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Utilizzare l'operazione Clear Configuration quando si desidera eliminare tutti i pool, i gruppi di volumi, i volumi, le definizioni host e le assegnazioni host dall'array di storage.

.Prima di iniziare
Prima di cancellare la configurazione dell'array di archiviazione, eseguire il backup dei dati.

.Informazioni su questa attività
Sono disponibili due opzioni Clear Storage Array Configuration:

* *Volume* -- In genere, potresti utilizzare l'opzione Volume per riconfigurare un array di storage di test come array di storage di produzione. Ad esempio, potresti configurare un array di storage per il test e poi, al termine del test, rimuovere la configurazione di test e configurare l'array di storage per un ambiente di produzione.
* *Array di storage* -- In genere, potresti utilizzare l'opzione Array di storage per spostare un array di storage in un altro reparto o gruppo. Ad esempio, potresti utilizzare un array di storage in Engineering e ora Engineering sta ricevendo un nuovo array di storage, quindi vuoi spostare l'array di storage attuale in Administration dove verrà riconfigurato.

[CAUTION]
====
*Rischio di perdita di dati* -- Questa operazione elimina tutti i dati dall'array di archiviazione. (Non esegue una cancellazione sicura.) Non è possibile annullare questa operazione dopo l'avvio. Eseguire questa operazione solo su indicazione del supporto tecnico.

====
.Passaggi
. Selezionare menu:Impostazioni[Sistema].
. Seleziona *Cancella configurazione array di archiviazione*.
. Nell'elenco a discesa, seleziona *Volume* o *Storage Array*.
. *Facoltativo:* Se si desidera salvare la configurazione (non i dati), utilizzare i link nella finestra di dialogo.
. Conferma che desideri eseguire l'operazione.


.Risultati
* La configurazione corrente viene eliminata, distruggendo tutti i dati esistenti sull'array di archiviazione.
* Tutte le unità sono non assegnate.
+

NOTE: L'array di storage si avvierà in modalità di ripristino. È necessario disattivare la modalità di ripristino prima di utilizzare l'array di storage. Vedere  https://docs.netapp.com/us-en/e-series-santricity/sm-support/clear-recovery-mode.html["Cancella modalità di ripristino"^] per ulteriori informazioni.

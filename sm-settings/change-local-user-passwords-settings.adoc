= Modificare le impostazioni della password dell'utente locale in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile impostare la lunghezza minima richiesta per tutte le nuove password degli utenti locali o per quelle aggiornate sull'array di storage. È inoltre possibile consentire agli utenti locali di accedere all'array di storage senza immettere una password.

.Prima di iniziare
È necessario aver effettuato l'accesso come amministratore locale, il che include i permessi di Root admin.

.Informazioni su questa attività
Tenete a mente queste linee guida quando impostate la lunghezza minima per le password degli utenti locali:

* Le modifiche alle impostazioni non influiranno sulle password degli utenti locali esistenti.
* La lunghezza minima richiesta per le password degli utenti locali deve essere compresa tra 0 e 30 caratteri.
* Qualsiasi nuova password utente locale deve soddisfare o superare l'impostazione attuale della lunghezza minima.
* Non impostare una lunghezza minima per la password se desideri che gli utenti locali accedano all'array di storage senza inserire una password.


.Passaggi
. Selezionare menu:Settings[Access Management].
. Seleziona la scheda *Ruoli utente locali*.
. Seleziona il pulsante *Visualizza/Modifica impostazioni*.
+
Si apre la finestra di dialogo Impostazioni password utente locale.

. Eseguire una delle seguenti operazioni:
+
** Per consentire agli utenti locali di accedere all'array di archiviazione _senza_ inserire una password, deselezionare la casella di controllo "Richiedi che tutte le password degli utenti locali siano almeno".
** Per impostare una lunghezza minima per tutte le password degli utenti locali, seleziona la casella di controllo "Richiedi che tutte le password degli utenti locali siano almeno di" e poi utilizza la casella di selezione numerica per impostare la lunghezza minima richiesta per tutte le password degli utenti locali.
+
Le nuove password degli utenti locali devono soddisfare o superare l'impostazione attuale.



. Fare clic su *Save*.

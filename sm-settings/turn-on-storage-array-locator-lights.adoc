= Attiva le spie di localizzazione dell'array di storage in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Per individuare la posizione fisica di un array di storage in un armadio, è possibile accendere le luci di localizzazione (LED).

.Passaggi
. Selezionare menu:Impostazioni[Sistema].
. In *Generale*, fare clic su *Attiva le spie di localizzazione dell'array di storage*.
+
La finestra di dialogo Attiva le spie di localizzazione dell'array di storage si apre e le spie di localizzazione dell'array di storage corrispondente si accendono.

. Quando hai individuato fisicamente lo storage array, torna alla finestra di dialogo e seleziona *Turn Off*.


.Risultati
Le spie di localizzazione si spengono e la finestra di dialogo si chiude.

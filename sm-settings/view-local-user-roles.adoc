= Visualizza i ruoli utente locali in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nella scheda Ruoli utente locali, è possibile visualizzare le mappature dei profili utente ai ruoli predefiniti. Queste mappature fanno parte dei controlli di accesso in base al ruolo (role-based access controls, RBAC) applicati nell'array di storage.

.Prima di iniziare
È necessario aver effettuato l'accesso con un profilo utente che includa le autorizzazioni di Security admin. In caso contrario, le funzioni di Access Management non vengono visualizzate.

.Informazioni su questa attività
I profili utente e le mappature non possono essere modificati. Solo le password possono essere modificate.

.Passaggi
. Selezionare menu:Settings[Access Management].
. Seleziona la scheda *Ruoli utente locali*.
+
I profili utente sono mostrati nella tabella:

+
** *Amministratore root* (admin) -- Super amministratore con accesso a tutte le funzioni del sistema. Questo profilo utente include tutti i ruoli.
** *Amministratore dello storage* (storage) -- L'amministratore responsabile di tutto il provisioning dello storage. Questo profilo utente include i seguenti ruoli: Storage Admin, Support Admin e Monitor.
** *Amministratore della sicurezza* (security) -- L'utente responsabile della configurazione della sicurezza, inclusa la gestione degli accessi, la gestione dei certificati e le funzioni delle unità secure-enabled. Questo profilo utente include i seguenti ruoli: Security Admin e Monitor.
** *Support admin* (support) -- L'utente responsabile delle risorse hardware, dei dati relativi ai guasti e degli aggiornamenti del firmware. Questo profilo utente include i seguenti ruoli: Support Admin e Monitor.
** *Monitor* (monitor) -- Un utente con accesso di sola lettura al sistema. Questo profilo utente include solo il ruolo Monitor.

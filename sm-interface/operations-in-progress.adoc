= Scopri le operazioni in corso nella pagina delle operazioni di SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La pagina Operazioni in corso consente di visualizzare un elenco di operazioni di lunga durata attualmente in esecuzione o in stato sospeso, interrotto o non riuscito. È possibile intervenire su determinati tipi di operazioni.

Le operazioni di lunga durata possono influire sulle prestazioni del sistema. Per alcune operazioni, si ha la possibilità di interrompere l'operazione o modificarne la priorità in modo che le operazioni più importanti vengano completate per prime.

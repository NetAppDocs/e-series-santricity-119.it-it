= Gestisci la protezione tramite password in SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È necessario configurare l'array di archiviazione con password per proteggerlo da accessi non autorizzati.



[[set-and-change-passwords]]
== Imposta e modifica le password

Quando si avvia System Manager per la prima volta, viene richiesto di impostare una password di amministratore. Qualsiasi utente in possesso della password di amministratore può apportare modifiche alla configurazione dell'array di storage, come l'aggiunta, la modifica o la rimozione di oggetti o impostazioni. Per impostare la password di amministratore durante l'avvio iniziale, vedere link:../san-getstarted/access-sam.html["Accedi a System Manager"].

Per motivi di sicurezza, puoi tentare di inserire una password solo cinque volte prima che l'array di storage entri in uno stato di "blocco". In questo stato, l'array di storage rifiuterà i successivi tentativi di inserimento della password. Devi attendere 10 minuti affinché l'array di storage si reimposti in uno stato "normale" prima di provare nuovamente a inserire una password.

Oltre alla password di amministratore, l'array di storage include profili utente predefiniti con uno o più ruoli associati. Per ulteriori informazioni, vedere link:../sm-settings/permissions-for-mapped-roles.html["Autorizzazioni per i ruoli mappati"]. I profili utente e le mappature non possono essere modificati. Solo le password possono essere modificate. Se si desidera modificare la password di amministratore o le password di altri utenti, vedere link:../sm-settings/change-passwords.html["Modifica password"].



[[re-enter-passwords-after-session-timeouts]]
== Reinserisci le password dopo il timeout della sessione

Il sistema richiede la password una sola volta durante una singola sessione di gestione. Tuttavia, una sessione scade dopo 30 minuti di inattività, momento in cui è necessario inserire nuovamente la password. Se un altro utente che gestisce lo stesso storage array da un altro client di gestione modifica la password mentre la tua sessione è in corso, ti verrà richiesta la password la prossima volta che tenterai un'operazione di configurazione o di visualizzazione.

È possibile regolare il timeout della sessione oppure disabilitare completamente i timeout della sessione. Vedi link:../sm-settings/manage-session-timeouts-sam.html["Gestisci i timeout di sessione"].



[[remove-drives-or-password-protection]]
== Rimuovere le unità o la protezione tramite password

Se si rimuovono unità protette da password o si desidera disabilitare la protezione tramite password, tenere presente quanto segue:

* *Se si rimuovono unità protette da password* -- La password è memorizzata in un'area riservata di ciascuna unità nell'array di storage. Se si rimuovono tutte le unità da un array di storage, la password non funzionerà più. Per correggere questa condizione, reinstallare una delle unità originali nell'array di storage.
* *Se si desidera rimuovere la protezione tramite password* -- Se non si desidera più che i comandi siano protetti da password, inserire la password di amministratore corrente e lasciare vuote le caselle di testo della nuova password.


[CAUTION]
====
L'esecuzione di comandi di configurazione su un array di storage può causare gravi danni, inclusa la perdita di dati. Per questo motivo, dovresti sempre impostare una password di amministratore per il tuo array di storage. Usa una password di amministratore lunga, con almeno 15 caratteri alfanumerici, per aumentare la sicurezza.

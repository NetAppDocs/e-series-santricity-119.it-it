= Scopri le notifiche relative ai problemi di SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager utilizza icone e diversi altri metodi per notificare che esistono problemi con l'array di storage.



[[icons]]
== Icone

System Manager utilizza queste icone per indicare lo stato dell'array di storage e dei suoi componenti.

System Manager visualizza queste icone in varie posizioni.

* Nell'area Notifiche della Home page vengono visualizzati l'icona di errore e un messaggio.
* L'icona della pagina iniziale nell'area di navigazione visualizza l'icona di errore.
* Nella pagina Componenti, la grafica relativa a unità e controller visualizza l'icona di errore.




[[alerts-and-leds]]
== Avvisi e LED

Inoltre, System Manager ti notifica i problemi anche in altri modi.

* System Manager invia notifiche SNMP o messaggi di errore email.
* I LED Service Action Required sull'hardware si accendono.


Quando ricevi una notifica di un problema, utilizza il Recovery Guru per aiutarti a risolvere il problema. Se necessario, utilizza la documentazione hardware insieme ai passaggi di ripristino per sostituire i componenti guasti.

= Visualizza il file di log AutoSupport in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il registro AutoSupport fornisce informazioni sullo stato, la cronologia delle spedizioni e gli errori riscontrati durante la consegna delle spedizioni AutoSupport.

.Informazioni su questa attività
Possono esistere più file di log. Quando il file di log corrente raggiunge i 200 KB, viene archiviato e viene creato un nuovo file di log. Il nome del file di log archiviato è  `ASUPMessages.n`, dove _n_ è un numero intero da 1 a 9. Se esistono più file di log, è possibile scegliere di visualizzare il log più recente o uno precedente.

* *Registro corrente* -- Mostra un elenco degli ultimi eventi acquisiti.
* *Registro archiviato* -- Mostra un elenco di eventi precedenti.


.Passaggi
. Selezionare menu:Supporto[Support Center > AutoSupport] scheda.
. Seleziona *Visualizza AutoSupport Log*.
+
Viene visualizzata una finestra di dialogo che elenca il registro AutoSupport corrente.

. Se desideri visualizzare i registri AutoSupport precedenti, seleziona il pulsante di opzione *Archiviati* e poi seleziona un registro dall'elenco a discesa *Seleziona registro AutoSupport*.
+
L'opzione Archiviati viene visualizzata solo se esistono log archiviati sull'array di storage.

+
Il registro AutoSupport selezionato viene visualizzato nella finestra di dialogo.

. *Facoltativo:* Per cercare nel registro AutoSupport, digita un termine nella casella *Trova* e fai clic su *Trova*.
+
Fai clic su *Trova* di nuovo per cercare altre occorrenze del termine.

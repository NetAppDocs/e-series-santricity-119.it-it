= Visualizza i ruoli utente locali
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dalla scheda Ruoli utente locali, è possibile visualizzare le mappature degli utenti ai ruoli predefiniti. Queste mappature fanno parte del controllo degli accessi in base al ruolo (RBAC) applicato nel Web Services Proxy per SANtricity Unified Manager.

.Prima di iniziare
È necessario aver effettuato l'accesso con un profilo utente che includa le autorizzazioni di Security admin. In caso contrario, le funzioni di Access Management non vengono visualizzate.

.Informazioni su questa attività
Gli utenti e le mappature non possono essere modificati. Solo le password possono essere modificate.

.Passaggi
. Seleziona *Access Management*.
. Seleziona la scheda *Ruoli utente locali*.
+
Gli utenti sono visualizzati nella tabella:

+
** *admin* -- Super amministratore con accesso a tutte le funzioni del sistema. Questo utente include tutti i ruoli.
** *storage* -- L'amministratore responsabile di tutto il provisioning dello storage. Questo utente include i seguenti ruoli: Storage Admin, Support Admin e Monitor.
** *sicurezza* -- L'utente responsabile della configurazione della sicurezza, inclusa Access Management e Certificate Management. Questo utente include i seguenti ruoli: Security Admin e Monitor.
** *support* -- L'utente responsabile delle risorse hardware, dei dati relativi ai guasti e degli aggiornamenti del firmware. Questo utente include i seguenti ruoli: Support Admin e Monitor.
** *monitor* -- Un utente con accesso di sola lettura al sistema. Questo utente include solo il ruolo Monitor.
** *rw* (lettura/scrittura) -- Questo utente include i seguenti ruoli: Storage Admin, Support Admin e Monitor.
** *ro* (read only) -- Questo utente include solo il ruolo Monitor.

= Esporta certificati in SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile esportare un certificato per visualizzarne tutti i dettagli completi.

.Prima di iniziare
Per aprire il file esportato, è necessario disporre di un'applicazione per la visualizzazione dei certificati.

.Passaggi
. Seleziona *Certificate Management*.
. Seleziona una delle seguenti schede:
+
** *Management* -- Mostra il certificato per il sistema che ospita il Web Services Proxy. Un certificato di management può essere autofirmato o approvato da una certificate authority (CA). Consente l'accesso sicuro a Unified Manager.
** *Attendibili* -- Mostra i certificati a cui Unified Manager può accedere per gli array di storage e altri server remoti, come un LDAP server. I certificati possono essere emessi da una certificate authority (CA) o possono essere self-signed.


. Seleziona un certificato dalla pagina, quindi fai clic sui puntini di sospensione alla fine della riga.
. Fai clic su *Export* e poi salva il file del certificato.
. Apri il file nell'applicazione per la visualizzazione dei certificati.

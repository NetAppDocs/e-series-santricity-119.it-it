= Modificare le password per i profili utente locali in SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile modificare le password degli utenti per ciascun utente in Access Management.

.Prima di iniziare
* È necessario aver effettuato l'accesso come amministratore locale, il che include i permessi di Root admin.
* È necessario conoscere la password dell'amministratore locale.


.Informazioni su questa attività
Tieni a mente queste linee guida quando scegli una password:

* Le nuove password degli utenti locali devono soddisfare o superare l'impostazione corrente per la password minima (in Visualizza/Modifica impostazioni).
* Le password distinguono tra maiuscole e minuscole.
* Gli spazi finali non vengono rimossi dalle password quando vengono impostate. Fai attenzione a includere gli spazi se erano inclusi nella password.
* Per una maggiore sicurezza, usa almeno 15 caratteri alfanumerici e cambia la password frequentemente.


.Passaggi
. Seleziona *Access Management*.
. Seleziona la scheda *Ruoli utente locali*.
. Seleziona un utente dalla tabella.
+
Il pulsante Change Password diventa disponibile.

. Seleziona *Change Password*.
+
Si apre la finestra di dialogo Change Password.

. Se non è impostata alcuna lunghezza minima per le password degli utenti locali, puoi selezionare la casella di controllo per richiedere all'utente di inserire una password per accedere al sistema.
. Inserisci la nuova password per l'utente selezionato nei due campi.
. Inserisci la password dell'amministratore locale per confermare questa operazione, quindi fai clic su *Cambia*.


.Risultati
Se l'utente è attualmente connesso, la modifica della password causa la terminazione della sessione attiva dell'utente.

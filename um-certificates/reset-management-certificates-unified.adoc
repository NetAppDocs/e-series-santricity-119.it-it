= Reimposta i certificati di gestione
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile ripristinare il certificato di gestione allo stato originale, autofirmato di fabbrica.

.Prima di iniziare
È necessario aver effettuato l'accesso con un profilo utente che includa le autorizzazioni di Security admin. In caso contrario, le funzioni dei certificati non vengono visualizzate.

.Informazioni su questa attività
Questa operazione elimina il certificato di gestione corrente dal sistema host in cui sono installati Web Services Proxy e Unified Manager. Dopo il ripristino del certificato, il sistema host torna a utilizzare il certificato autofirmato.

.Passaggi
. Seleziona *Impostazioni > Certificati*.
. Seleziona la scheda *Array Management*, quindi seleziona *Reset*.
+
Si apre una finestra di dialogo Confirm Reset Management Certificate.

. Digita `reset` nel campo, quindi fai clic su *Ripristina*.
+
Dopo l'aggiornamento della pagina, il browser potrebbe bloccare l'accesso al sito di destinazione e segnalare che il sito utilizza HTTP Strict Transport Security. Questa condizione si verifica quando si torna a utilizzare certificati autofirmati. Per eliminare la condizione che blocca l'accesso alla destinazione, è necessario cancellare i dati di navigazione dal browser.



.Risultati
Il sistema torna a utilizzare il certificato autofirmato del server. Di conseguenza, il sistema richiede agli utenti di accettare manualmente il certificato autofirmato per le proprie sessioni.

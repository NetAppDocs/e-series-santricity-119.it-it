= Modificare le impostazioni della password dell'utente locale in SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile impostare la lunghezza minima richiesta per tutte le nuove password degli utenti locali o per quelle aggiornate. È inoltre possibile consentire agli utenti locali di accedere al sistema senza inserire una password.

.Prima di iniziare
È necessario aver effettuato l'accesso come amministratore locale, il che include i permessi di Root admin.

.Informazioni su questa attività
Tenete a mente queste linee guida quando impostate la lunghezza minima per le password degli utenti locali:

* Le modifiche alle impostazioni non influiscono sulle password degli utenti locali esistenti.
* La lunghezza minima richiesta per le password degli utenti locali deve essere compresa tra 0 e 30 caratteri.
* Qualsiasi nuova password utente locale deve soddisfare o superare l'impostazione attuale della lunghezza minima.
* Non impostare una lunghezza minima per la password se desideri che gli utenti locali accedano al sistema senza inserire una password.


.Passaggi
. Seleziona *Access Management*.
. Seleziona la scheda *Ruoli utente locali*.
. Seleziona *Visualizza/Modifica impostazioni*.
+
Si apre la finestra di dialogo Impostazioni password utente locale.

. Eseguire una delle seguenti operazioni:
+
** Per consentire agli utenti locali di accedere al sistema _senza_ inserire una password, deselezionare la casella di controllo "Require all local user passwords to be at least".
** Per impostare una lunghezza minima per tutte le password degli utenti locali, selezionare la casella di controllo "Richiedi che tutte le password degli utenti locali siano almeno di" e quindi utilizzare la casella di selezione numerica per impostare la lunghezza minima richiesta per tutte le password degli utenti locali.
+
Le nuove password degli utenti locali devono soddisfare o superare l'impostazione attuale.



. Fare clic su *Save*.

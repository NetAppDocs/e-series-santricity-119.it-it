= Scopri il mirroring sincrono nel software SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La funzionalità di mirroring sincrono fornisce replica dei dati in real-time tra array di storage su una distanza remota.

[NOTE]
====
Questa funzionalità non è disponibile sui sistemi storage EF600/EF600C o EF300/EF300C.

====


== Che cos'è il mirroring sincrono?

Il mirroring sincrono replica i volumi di dati in real-time per garantire disponibilità continua. I controller degli array di storage gestiscono l'operazione di mirroring, che è trasparente per le macchine host e le applicazioni software.

Questo tipo di mirroring è ideale per scopi di continuità operativa, come il disaster recovery.

== Come si configura il mirroring sincrono?

È necessario utilizzare l'interfaccia di Unified Manager per eseguire la configurazione iniziale del mirroring tra gli array. Una volta configurato, è possibile gestire le coppie mirrorate in System Manager.

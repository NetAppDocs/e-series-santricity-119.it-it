= Installare SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager è incluso con il Web Services Proxy, che è un server API RESTful installato separatamente su un sistema host per gestire i sistemi storage NetApp E-Series.

Per installare Web Services Proxy e Unified Manager, consultare le seguenti istruzioni nel centro documentazione di E-Series e SANtricity:

. https://docs.netapp.com/us-en/e-series/web-services-proxy/install-reqs-task.html["Esaminare i requisiti di installazione e aggiornamento"^]
. https://docs.netapp.com/us-en/e-series/web-services-proxy/install-wsp-task.html["Scarica e installa il file Web Services Proxy"^]

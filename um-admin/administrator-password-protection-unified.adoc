= Scopri la protezione della password di amministratore in SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È necessario configurare SANtricity Unified Manager con una password di amministratore per proteggerlo da accessi non autorizzati.



[[admin-password-and-user-profiles]]
== Password di amministratore e profili utente

Quando si avvia Unified Manager per la prima volta, viene richiesto di impostare una password di amministratore. Qualsiasi utente che dispone della password di amministratore può apportare modifiche alla configurazione degli storage arrays.

Oltre alla password di amministratore, l'interfaccia di Unified Manager include profili utente preconfigurati con uno o più ruoli associati. Per ulteriori informazioni, vedere link:../um-certificates/how-access-management-works-unified.html["Come funziona la gestione degli accessi"].

Non è possibile modificare gli utenti e le mappature. È possibile modificare solo le password. Per modificare le password, consultare:

* link:change-admin-password-unified.html["Cambia la password dell'amministratore"]
* link:../um-certificates/change-passwords-unified.html["Modifica le password per i profili utente locali"]




[[session-timeouts]]
== Timeout di sessione

Il software richiede la password una sola volta durante una singola sessione di gestione. Una sessione scade dopo 30 minuti di inattività per impostazione predefinita, momento in cui è necessario inserire nuovamente la password. Se un altro utente accede al software da un altro client di gestione e modifica la password mentre la tua sessione è in corso, ti verrà richiesta la password la prossima volta che tenterai un'operazione di configurazione o di visualizzazione.

Per motivi di sicurezza, è possibile tentare di inserire una password solo cinque volte prima che il software entri in stato di "lockout". In questo stato, il software rifiuta i successivi tentativi di inserimento della password. È necessario attendere 10 minuti affinché il sistema torni in stato "normale" prima di poter provare a inserire nuovamente la password.

È possibile regolare i timeout di sessione oppure disabilitare completamente i timeout di sessione. Per ulteriori informazioni, vedere link:manage-session-timeouts-unified.html["Gestisci i timeout di sessione"].

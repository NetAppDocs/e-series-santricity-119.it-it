= Scopri SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager è un'interfaccia basata su web che consente di gestire più array di storage in un'unica visualizzazione.



== Pagina principale

Quando accedi a Unified Manager, la pagina principale si apre su *Manage - All*. Da questa pagina, puoi scorrere un elenco di array di storage rilevati nella tua rete, visualizzarne lo stato ed eseguire operazioni su un singolo array o su un gruppo di array.



== Barra laterale di navigazione

È possibile accedere alle funzionalità e alle funzioni di Unified Manager dalla barra laterale di navigazione.

[cols="25h,~"]
|===
| Area | Descrizione 


 a| 
Gestire
 a| 
Scopri gli array di storage nella tua rete, avvia SANtricity System Manager per un array, importa le impostazioni da un array a più array e gestisci i gruppi di array. Seleziona le caselle di controllo accanto ai nomi degli array per eseguire operazioni su di essi, come importare le impostazioni e creare gruppi di array. I puntini di sospensione alla fine di ogni riga forniscono un menu inline per le operazioni su un singolo array, come la ridenominazione.



 a| 
Operazioni
 a| 
Visualizza l'avanzamento delle operazioni batch, come l'importazione delle impostazioni da un array a un altro.

[NOTE]
====
Alcune operazioni non sono disponibili quando un array di storage ha uno stato non ottimale.

====


 a| 
Gestione dei certificati
 a| 
Gestisci i certificati per autenticare tra browser e client.



 a| 
Gestione degli accessi
 a| 
Stabilire l'autenticazione utente per l'interfaccia Unified Manager.



 a| 
Supporto
 a| 
Visualizza le opzioni di supporto tecnico, le risorse e i contatti.

|===


== Impostazioni dell'interfaccia e guida

In alto a destra dell'interfaccia, puoi accedere alla Guida e ad altra documentazione. Puoi anche accedere alle opzioni di amministrazione, disponibili dal menu a tendina accanto al tuo nome di accesso.



== Accessi utente e password

L'utente attualmente connesso al sistema viene visualizzato in alto a destra dell'interfaccia.

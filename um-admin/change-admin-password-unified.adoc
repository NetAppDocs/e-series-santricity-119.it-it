= Modifica la password di admin in SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile modificare la password di amministratore utilizzata per accedere a SANtricity Unified Manager.

.Prima di iniziare
* È necessario aver effettuato l'accesso come amministratore locale, il che include i permessi di Root admin.
* È necessario conoscere la password admin corrente.


.Informazioni su questa attività
Tieni a mente queste linee guida quando scegli una password:

* Le password distinguono tra maiuscole e minuscole.
* Gli spazi finali non vengono rimossi dalle password quando vengono impostate. Fai attenzione a includere gli spazi se erano inclusi nella password.
* Per una maggiore sicurezza, usa almeno 15 caratteri alfanumerici e cambia la password frequentemente.


.Passaggi
. Selezionare menu:Settings[Access Management].
. Seleziona la scheda *Ruoli utente locali*.
. Seleziona l'utente *admin* dalla tabella.
+
Il pulsante Change Password diventa disponibile.

. Seleziona *Change Password*.
+
Si apre la finestra di dialogo Change Password.

. Se non è stata impostata una lunghezza minima per le password degli utenti locali, selezionare la casella di controllo per richiedere all'utente di immettere una password per accedere al sistema.
. Inserisci la nuova password nei due campi.
. Inserisci la password dell'amministratore locale per confermare questa operazione, quindi fai clic su *Cambia*.

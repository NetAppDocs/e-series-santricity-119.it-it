= Modificare le password degli array di storage in SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile aggiornare le password utilizzate per visualizzare e accedere agli array di storage in SANtricity Unified Manager.

.Prima di iniziare
* È necessario aver effettuato l'accesso con un profilo utente che includa le autorizzazioni Storage admin.
* È necessario conoscere la password corrente per l'array di storage, che è impostata in System Manager.


.Informazioni su questa attività
In questa attività, si immette la password corrente per un array di storage in modo da potervi accedere in Unified Manager. Ciò potrebbe essere necessario se la password dell'array è stata modificata in System Manager e ora deve essere modificata anche in Unified Manager.

.Passaggi
. Dalla pagina Manage, seleziona uno o più storage array.
. Selezionare menu:Uncommon Tasks[Provide Storage Array Passwords].
. Inserisci la password o le password per ciascun array di archiviazione, quindi fai clic su *Save*.

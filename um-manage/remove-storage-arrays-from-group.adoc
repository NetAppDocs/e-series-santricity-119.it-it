= Rimuovi gli array di storage da un gruppo in SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile rimuovere uno o più array di storage gestiti da un gruppo se non si desidera più gestirli da uno specifico storage group.

.Informazioni su questa attività
La rimozione di storage array da un gruppo non influisce in alcun modo sullo storage array o sui suoi dati. Se il tuo storage array è gestito da System Manager, puoi comunque gestirlo utilizzando il browser. Se uno storage array viene rimosso accidentalmente da un gruppo, può essere aggiunto di nuovo.

.Passaggi
. Dalla pagina Manage, selezionare menu:Manage Groups[Remove storage arrays from group].
. Dal menu a tendina, seleziona il gruppo che contiene gli array di storage che desideri rimuovere, e poi fai clic sulla check box accanto a ciascun array di storage che desideri rimuovere dal gruppo.
. Fai clic su *Remove*.

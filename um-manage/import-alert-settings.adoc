= Importa le impostazioni degli avvisi in SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile importare le configurazioni degli avvisi da un array di storage ad altri array di storage. Questa operazione in batch consente di risparmiare tempo quando è necessario configurare più array nella rete.

.Prima di iniziare
* Gli avvisi vengono configurati in System Manager per l'array di storage che si desidera utilizzare come origine (menu:Settings[Alerts]).
* La configurazione esistente per gli array di storage di destinazione viene salvata in System Manager (menu: Impostazioni [Sistema > Salva configurazione array di storage]).


.Informazioni su questa attività
È possibile selezionare avvisi email, SNMP o syslog per l'operazione di importazione. Le impostazioni importate includono:

* *Avvisi email* -- Un indirizzo del server di posta e gli indirizzi email dei destinatari degli avvisi.
* *Avvisi syslog* -- Un indirizzo del server syslog e una porta UDP.
* *Avvisi SNMP* -- Un nome della community e un indirizzo IP per il server SNMP.


.Passaggi
. Dalla pagina Manage, fai clic su *Import Settings*.
+
Si apre la procedura guidata Import Settings.

. Nella finestra di dialogo Seleziona impostazioni, seleziona *Email alerts*, *SNMP alerts* o *Syslog alerts*, quindi fai clic su *Avanti*.
+
Si apre una finestra di dialogo per selezionare l'array di origine.

. Nella finestra di dialogo Seleziona origine, seleziona l'array con le impostazioni che desideri importare, quindi fai clic su *Next*.
. Nella finestra di dialogo Seleziona destinazioni, seleziona una o più matrici per ricevere le nuove impostazioni.
+
[NOTE]
====
Gli array di storage con firmware inferiore a 8.50 non sono disponibili per la selezione. Inoltre, un array non viene visualizzato in questa finestra di dialogo se Unified Manager non può comunicare con quell'array (ad esempio, se è offline o se presenta problemi di certificato, password o di rete).

====
. Fare clic su *Fine*.
+
La pagina Operazioni mostra i risultati dell'operazione di importazione. Se l'operazione non riesce, puoi fare clic sulla sua riga per vedere ulteriori informazioni.



.Risultati
Gli array di storage di destinazione sono ora configurati per inviare avvisi agli amministratori tramite email, SNMP o syslog.

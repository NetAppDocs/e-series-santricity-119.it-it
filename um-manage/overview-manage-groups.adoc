= Scopri la panoramica dei gruppi in SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dalla pagina Manage Groups, è possibile creare un set di gruppi di array di storage per una gestione più semplice.



== Che cosa sono i gruppi di array?

È possibile gestire l'infrastruttura fisica e virtualizzata raggruppando un insieme di array di storage. Potresti voler raggruppare gli array di storage per semplificare l'esecuzione di attività di monitoraggio o di reporting.

Esistono due tipi di gruppi:

* *All group* -- Il gruppo All è il gruppo predefinito e include tutti gli array di storage rilevati nell'organizzazione. È possibile accedere al gruppo All dalla vista principale.
* *Gruppo creato dall'utente* -- Un gruppo creato dall'utente include gli array di storage che si selezionano manualmente per aggiungerli a quel gruppo. È possibile accedere ai gruppi creati dall'utente dalla vista principale.




== Come si configurano i gruppi?

Dalla pagina Manage Groups, è possibile creare un gruppo e quindi aggiungere array a tale gruppo.

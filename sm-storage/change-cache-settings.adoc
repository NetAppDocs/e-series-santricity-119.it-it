= Modificare le impostazioni della cache per un volume in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile modificare le impostazioni della cache di lettura e della cache di scrittura per influire sulle prestazioni I/O complessive di un volume.

.Informazioni su questa attività
Tenete a mente queste linee guida quando modificate le impostazioni della cache per un volume:

* Dopo aver aperto la finestra di dialogo Modifica impostazioni cache, potresti visualizzare un'icona accanto alle proprietà della cache selezionate. Questa icona indica che il controller ha temporaneamente sospeso le operazioni di caching.
+
Questa azione potrebbe verificarsi quando una nuova batteria si sta caricando, quando un controller è stato rimosso o se il controller ha rilevato una discrepanza nelle dimensioni della cache. Dopo che la condizione è stata risolta, le proprietà della cache selezionate nella finestra di dialogo diventano attive. Se le proprietà della cache selezionate non diventano attive, contattare il supporto tecnico.

* È possibile modificare le impostazioni della cache per un singolo volume o per più volumi su un array di storage. È possibile modificare le impostazioni della cache per tutti i volumi standard o per tutti i volumi thin contemporaneamente.


.Passaggi
. Selezionare menu:Storage[Volumes].
. Seleziona un volume qualsiasi, quindi seleziona menu:Altro[Modifica impostazioni cache].
+
Viene visualizzata la finestra di dialogo Modifica impostazioni cache. Tutti i volumi sull'array di storage vengono visualizzati in questa finestra di dialogo.

. Seleziona la scheda *Basic* per modificare le impostazioni della cache di lettura e della cache di scrittura.
+
.Dettagli del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Impostazione della cache | Descrizione 


 a| 
Cache di lettura
 a| 
La cache di lettura è un buffer che memorizza i dati letti dalle unità. I dati per un'operazione di lettura potrebbero essere già presenti nella cache da un'operazione precedente, eliminando la necessità di accedere alle unità. I dati rimangono nella cache di lettura finché non vengono svuotati.



 a| 
Cache di scrittura
 a| 
La cache di scrittura è un buffer che memorizza i dati provenienti dall'host che non sono ancora stati scritti sulle unità. I dati rimangono nella cache di scrittura finché non vengono scritti sulle unità. La cache di scrittura può aumentare le prestazioni di I/O.


NOTE: La cache viene svuotata automaticamente dopo che la *Write caching* è stata disabilitata per un volume.

|===
====
. Seleziona la scheda *Advanced* per modificare le impostazioni avanzate per i volumi thick. Le impostazioni avanzate della cache sono disponibili solo per i volumi thick.
+
.Dettagli del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Impostazione della cache | Descrizione 


 a| 
Precaricamento dinamico della cache di lettura
 a| 
Il precaricamento dinamico della cache di lettura consente al controller di copiare ulteriori blocchi di dati sequenziali nella cache mentre legge i blocchi di dati da un'unità alla cache. Questo caching aumenta la probabilità che le future richieste di dati possano essere soddisfatte dalla cache. Il precaricamento dinamico della cache di lettura è importante per le applicazioni multimediali che utilizzano I/O sequenziale. La velocità e la quantità di dati precaricati nella cache si regolano automaticamente in base alla velocità e alla dimensione delle richieste di lettura dell'host. L'accesso casuale non comporta il precaricamento dei dati nella cache. Questa funzionalità non si applica quando il caching di lettura è disabilitato.

Per un volume thin, il precaricamento dinamico della cache di lettura è sempre disabilitato e non può essere modificato.



 a| 
Cache di scrittura senza batteria
 a| 
L'impostazione cache di scrittura senza batterie consente alla cache di scrittura di continuare anche quando le batterie sono mancanti, guaste, completamente scariche o non completamente cariche. La scelta della cache di scrittura senza batterie non è generalmente raccomandata, perché i dati potrebbero andare persi in caso di perdita di alimentazione. In genere, la cache di scrittura viene disattivata temporaneamente dal controller fino a quando le batterie non sono cariche o una batteria guasta viene sostituita.


CAUTION: *Possibile perdita di dati* -- Se si seleziona questa opzione e non si dispone di un alimentatore universale di protezione, si potrebbero perdere dati. Inoltre, si potrebbero perdere dati se non si dispone di batterie per il controller e si abilita l'opzione *Write caching without batteries*.

Questa impostazione è disponibile solo se è stata abilitata la cache di scrittura. Questa impostazione non è disponibile per i volumi thin.



 a| 
Cache di scrittura con mirroring
 a| 
La cache di scrittura con mirroring si verifica quando i dati scritti nella cache di un controller vengono scritti anche nella cache dell'altro controller. Pertanto, se un controller si guasta, l'altro può completare tutte le operazioni di scrittura in sospeso. Il mirroring della cache di scrittura è disponibile solo se la cache di scrittura è abilitata e sono presenti due controller. La cache di scrittura con mirroring è l'impostazione predefinita alla creazione del volume.

Questa impostazione è disponibile solo se è stata abilitata la cache di scrittura. Questa impostazione non è disponibile per i volumi thin.

|===
====
. Fai clic su *Salva* per modificare le impostazioni della cache.

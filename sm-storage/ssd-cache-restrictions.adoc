= Scopri le limitazioni della Cache SSD nel software SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Scopri le limitazioni relative all'utilizzo della Cache SSD sul tuo array di storage.



[[restrictions]]
== Restrizioni

* Qualsiasi volume assegnato all'utilizzo della Cache SSD di un controller non è idoneo per un trasferimento automatico del bilanciamento del carico.
* Attualmente, è supportata una sola Cache SSD per array di storage.
* La capacità massima di Cache SSD utilizzabile su un array di storage è di 10 TB.
* Cache SSD non è supportata sulle immagini snapshot.
* Se si importano o esportano volumi con Cache SSD abilitata o disabilitata, i dati memorizzati nella cache non vengono importati o esportati.
* Non è possibile rimuovere l'ultima unità in una Cache SSD senza prima eliminare la Cache SSD.




[[restrictions-with-drive-security]]
== Restrizioni con Drive Security

* È possibile abilitare la sicurezza sulla Cache SSD solo quando si crea la Cache SSD. Non è possibile abilitare la sicurezza in un secondo momento come si può fare su un volume.
* Se si combinano unità compatibili con la sicurezza con unità non compatibili con la sicurezza nella Cache SSD, non è possibile abilitare Drive Security per queste unità.
* I volumi secure-enabled devono avere una Cache SSD secure-enabled.

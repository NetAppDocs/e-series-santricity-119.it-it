= Monitorare i thin volume in SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile monitorare i thin volumes per lo spazio e generare avvisi appropriati, in modo da prevenire condizioni di esaurimento della capacità.

[NOTE]
====
Questa funzionalità non è disponibile sui sistemi storage EF600/EF600C o EF300/EF300C.

====
[NOTE]
====
SANtricity System Manager non offre la possibilità di creare volumi thin. Se si desidera creare volumi thin, utilizzare la Command Line Interface (CLI).

====

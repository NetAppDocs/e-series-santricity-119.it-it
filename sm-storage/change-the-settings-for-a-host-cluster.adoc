= Modificare le impostazioni per un cluster host in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile modificare il nome del cluster host oppure aggiungere o rimuovere host in un cluster host.

.Passaggi
. Seleziona menu:Storage[Hosts].
. Seleziona il cluster host che desideri modificare, quindi fai clic su *Visualizza/Modifica impostazioni*.
+
Viene visualizzata una finestra di dialogo che mostra le impostazioni correnti del cluster host.

. Modificare le impostazioni del cluster host in base alle necessità.
+
.Dettagli del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Impostazione | Descrizione 


 a| 
Nome
 a| 
È possibile specificare il nome fornito dall'utente per il cluster host. Specificare un nome per un cluster è obbligatorio.



 a| 
Host associati
 a| 
Per aggiungere un host, fai clic sulla casella *Associated Hosts* e seleziona un host name dall'elenco a discesa. Non è possibile inserire manualmente un host name.

Per eliminare un host, fai clic sulla *X* accanto al host name.

|===
====
. Fare clic su *Save*.

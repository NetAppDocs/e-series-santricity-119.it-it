= Scopri host e cluster di host nel software SANtricity
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile configurare host e cluster di host, che definiscono le connessioni tra l'array di storage e i server di dati.



[[what-are-hosts-and-host-clusters]]
== Che cosa sono gli host e i cluster di host?

Un host è un server che invia I/O a un volume su un array di storage. Un host cluster è un gruppo di host, che puoi creare per assegnare gli stessi volumi a più host.

Per saperne di più:

* link:host-terminology.html["Terminologia host"]
* link:access-volumes.html["Accesso ai volumi"]
* link:maximum-number-of-luns.html["Numero massimo di LUN"]




[[how-do-i-configure-hosts-and-host-clusters]]
== Come si configurano gli host e i cluster di host?

Per definire le connessioni host, puoi andare su menu:Storage[Hosts] per configurare manualmente l'host. Se desideri che due o più host condividano l'accesso allo stesso set di volumi, puoi quindi definire un cluster e assegnare i volumi a quel cluster.

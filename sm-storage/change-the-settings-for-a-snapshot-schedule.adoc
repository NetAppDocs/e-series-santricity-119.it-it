= Modifica le impostazioni per un calendario di Snapshot in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Per un calendario di Snapshot, è possibile modificare gli orari di raccolta automatica o la frequenza di raccolta.

.Informazioni su questa attività
È possibile importare le impostazioni da un calendario di Snapshot esistente oppure modificarle in base alle proprie esigenze.

Poiché un calendario di Snapshot è associato a un gruppo di Snapshot o a un gruppo di coerenza di Snapshot, la capacità riservata potrebbe essere influenzata dalle modifiche alle impostazioni del calendario.

.Passaggi
. Selezionare menu:Storage[Snapshots].
. Fai clic sulla scheda *Schedules*.
. Seleziona il calendario di Snapshot che desideri modificare, quindi fai clic su *Modifica*.
+
Viene visualizzata la finestra di dialogo Edit Snapshot Schedule.

. Eseguire una delle seguenti operazioni:
+
** *Utilizza un calendario definito in precedenza da un altro oggetto Snapshot* -- fai clic su *Importa calendario*, seleziona l'oggetto con il calendario che desideri importare e quindi fai clic su *Importa*.
** *Modifica le impostazioni del calendario* -- Fai riferimento ai dettagli del campo qui sotto.
+
.Dettagli del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Impostazione | Descrizione 


 a| 
Giorno/mese
 a| 
Scegli una delle seguenti opzioni:

*** *Giornaliero/Settimanale* -- Seleziona i singoli giorni per le Snapshot di sincronizzazione. Puoi anche selezionare la check box *Seleziona tutti i giorni* in alto a destra se desideri un calendario giornaliero.
*** *Mensile/Annuale* -- Seleziona i singoli mesi per le Snapshot di sincronizzazione. Nel campo *Giorno/i*, inserisci i giorni del mese in cui devono avvenire le sincronizzazioni. I valori validi sono da *1* a *31* e *Last*. Puoi separare più giorni con una virgola o un punto e virgola. Usa un trattino per le date inclusive. Ad esempio: 1,3,4,10-15,Last. Puoi anche selezionare la check box *Select all months* in alto a destra se desideri un calendario mensile.




 a| 
Ora di inizio
 a| 
Dal menu a tendina, seleziona un nuovo orario di inizio per le Snapshot giornaliere. Le opzioni sono disponibili con incrementi di mezz'ora. L'orario di inizio predefinito è mezz'ora avanti rispetto all'ora corrente.



 a| 
Fuso orario
 a| 
Dal menu a discesa, seleziona il fuso orario del tuo array di storage.



 a| 
Snapshot al giorno

Intervallo tra le Snapshot
 a| 
Seleziona il numero di immagini di Snapshot da creare al giorno.

Se si selezionano più punti di ripristino, selezionare anche l'intervallo di tempo tra i punti di ripristino. Per più punti di ripristino, assicurarsi di disporre di una capacità di riserva adeguata.



 a| 
Data di inizio

Data di fine

Nessuna data di fine
 a| 
Inserisci la data di inizio per l'avvio delle sincronizzazioni. Inserisci anche una data di fine oppure seleziona *No end date*.

|===
====


. Fare clic su *Save*.

= Scopri la creazione manuale di host in SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La creazione di un host è uno dei passaggi necessari per consentire all'array di storage di identificare gli host ad esso collegati e per autorizzare l'accesso I/O ai volumi. È possibile creare un host solo manualmente.



[[manual-creation]]
== Creazione manuale

La creazione manuale degli host consente di garantire che gli identificatori delle porte host rilevati dai controller dello storage array siano associati correttamente agli host.

Durante la creazione manuale di un host, si associano gli identificatori di porta dell'host selezionandoli da un elenco o inserendoli manualmente. Dopo aver creato un host, è possibile assegnargli volumi o aggiungerlo a un host cluster se si prevede di condividere l'accesso ai volumi.

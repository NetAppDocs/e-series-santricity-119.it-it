= Scopri volumi e carichi di lavoro in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile creare un volume come container in cui applicazioni, database e file system archiviano i dati. Durante la creazione di un volume, si seleziona anche un workload per personalizzare la configurazione dell'array di storage per una specifica applicazione.



== Cosa sono i volumi e i carichi di lavoro?

Un _volume_ è il componente logico creato con una capacità specifica a cui l'host può accedere. Sebbene un volume possa essere costituito da più unità, un volume appare come un unico componente logico all'host. Una volta definito un volume, puoi aggiungerlo a un carico di lavoro. Un _carico di lavoro_ è un oggetto di storage che supporta un'applicazione, come SQL Server o Exchange, che puoi utilizzare per ottimizzare lo storage per quell'applicazione.

== Come si creano volumi e workload?

Innanzitutto, si crea un carico di lavoro. Andare al menu:Storage[Volumes] e aprire una procedura guidata che guida l'utente attraverso i passaggi. Successivamente, si crea un volume dalla capacità disponibile in un pool o in un gruppo di volumi, e poi si assegna il carico di lavoro creato.

= Scopri la terminologia relativa alla capacità nel software SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Scopri come si applicano i termini relativi alla capacità al tuo storage array.



== Oggetti di storage

La seguente terminologia descrive i diversi tipi di oggetti di storage che possono interagire con il tuo storage array.

[cols="25h,~"]
|===
| Oggetto di storage | Descrizione 


 a| 
Host
 a| 
Un host è un server che invia I/O a un volume su un array di storage.



 a| 
LUN
 a| 
Un numero di unità logica (LUN) è il numero assegnato allo spazio di indirizzi che un host utilizza per accedere a un volume. Il volume viene presentato all'host come capacità sotto forma di LUN.

Ogni host dispone di un proprio spazio di indirizzamento LUN. Pertanto, lo stesso LUN può essere utilizzato da host diversi per accedere a volumi differenti.



 a| 
Gruppo di coerenza mirror
 a| 
Un gruppo di coerenza mirror è un container per una o più coppie mirror. Per le operazioni di mirroring asincrono, è necessario creare un gruppo di coerenza mirror.



 a| 
Coppia di volumi speculari
 a| 
Una coppia speculare è composta da due volumi, un volume primario e un volume secondario.



 a| 
Pool
 a| 
Un pool è un insieme di unità disco raggruppate logicamente. È possibile utilizzare un pool per creare uno o più volumi accessibili a un host. (È possibile creare volumi da un pool o da un gruppo di volumi.)



 a| 
Gruppo di coerenza Snapshot
 a| 
Un gruppo di coerenza snapshot è una raccolta di volumi che vengono trattati come un'unica entità quando viene creata un'immagine snapshot. Ciascuno di questi volumi ha la propria immagine snapshot, ma tutte le immagini vengono create nello stesso momento.



 a| 
Gruppo Snapshot
 a| 
Un gruppo di snapshot è una raccolta di immagini snapshot da un singolo volume di base.



 a| 
Volume Snapshot
 a| 
Un volume snapshot consente all'host di accedere ai dati nell'immagine snapshot. Il volume snapshot contiene una propria capacità riservata, che salva eventuali modifiche al volume di base senza influire sull'immagine snapshot originale.



 a| 
Volume
 a| 
Un volume è un container in cui applicazioni, database e file system memorizzano i dati. È il componente logico creato per consentire all'host di accedere allo storage sull'array di storage.



 a| 
Gruppo di volumi
 a| 
Un gruppo di volumi è un container per volumi con caratteristiche condivise. Un gruppo di volumi ha una capacità definita e livello RAID. È possibile utilizzare un gruppo di volumi per creare uno o più volumi accessibili a un host. (È possibile creare volumi da un gruppo di volumi o da un pool.)

|===


== Capacità di storage

La seguente terminologia descrive i diversi tipi di capacità utilizzati sullo storage array.

[cols="25h,~"]
|===
| Tipo di capacità | Descrizione 


 a| 
Capacità assegnata
 a| 
La capacità allocata è la capacità fisica allocata dalle unità in un pool o in un gruppo di volumi.

Si utilizza la capacità allocata per creare volumi e per le operazioni dei servizi di copia.



 a| 
Capacità libera
 a| 
La capacità libera è la capacità disponibile in un pool o in un gruppo di volumi che non è stata ancora allocata alla creazione di volumi, alle operazioni dei servizi di copia e agli oggetti di storage.



 a| 
Capacità del pool o del gruppo di volumi
 a| 
La capacità di un pool, di un volume o di un gruppo di volumi è la capacità in un array di storage che è stata assegnata a un pool o a un gruppo di volumi. Questa capacità viene utilizzata per creare volumi e soddisfare le varie esigenze di capacità delle operazioni dei servizi di copia e degli oggetti di storage.



 a| 
Capacità inutilizzabile del pool
 a| 
La capacità inutilizzabile di un pool è lo spazio in un pool che non può essere utilizzato a causa di dimensioni dei dischi non corrispondenti.



 a| 
Capacità di conservazione
 a| 
La capacità di conservazione è la quantità di capacità (numero di unità) che viene riservata in un pool per supportare potenziali guasti delle unità.



 a| 
Capacità segnalata
 a| 
La capacità segnalata è la capacità che viene comunicata all'host e a cui l'host può accedere.



 a| 
Capacità riservata
 a| 
La capacità riservata è la capacità fisica allocata utilizzata per qualsiasi operazione di copia del servizio e oggetto di archiviazione. Non è direttamente leggibile dall'host.



 a| 
Cache SSD
 a| 
Cache SSD è un insieme di unità a stato solido (SSD) che vengono raggruppate logicamente nell'array di storage. La funzionalità Cache SSD memorizza nella cache i dati a cui si accede più frequentemente (dati "caldi") su unità SSD a bassa latenza per accelerare dinamicamente i carichi di lavoro delle applicazioni.



 a| 
Capacità non assegnata
 a| 
La capacità non assegnata è lo spazio in un array di storage che *non* è stato assegnato a un pool o a un volume group.



 a| 
Capacità scritta
 a| 
La capacità scritta è la quantità di capacità che è stata scritta dalla capacità riservata allocata per i volumi sottili.

|===

= Modificare le impostazioni del volume per un volume Snapshot in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile modificare le impostazioni di un volume snapshot o di un volume snapshot di un gruppo di coerenza snapshot per rinominarlo, abilitare o disabilitare la cache SSD oppure modificare l'host, il cluster o l'assegnazione del numero di unità logica (LUN).

.Passaggi
. Selezionare menu:Storage[Snapshots].
. Fai clic sulla scheda *Snapshot Volumes*.
. Seleziona il volume Snapshot che desideri modificare, quindi fai clic su *Visualizza/Modifica impostazioni*.
+
Viene visualizzata la finestra di dialogo Impostazioni volume Snapshot.

. Visualizza o modifica le impostazioni per il volume Snapshot come appropriato.
+
.Dettagli del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Impostazione | Descrizione 


 a| 
*Volume Snapshot*



 a| 
Nome
 a| 
È possibile modificare il nome per il volume snapshot.



 a| 
Assegnato a
 a| 
È possibile modificare l'assegnazione dell'host o del cluster host per il volume Snapshot.



 a| 
LUN
 a| 
È possibile modificare l'assegnazione LUN per il volume Snapshot.



 a| 
Cache SSD
 a| 
È possibile abilitare/disabilitare la cache di sola lettura sui dischi a stato solido (SSDs).



 a| 
*Oggetti associati*



 a| 
Immagine Snapshot
 a| 
È possibile visualizzare le immagini Snapshot associate al volume Snapshot. Un'immagine Snapshot è una copia logica dei dati del volume, acquisita in un determinato point-in-time. Analogamente a un punto di ripristino, le immagini Snapshot consentono di tornare a un set di dati funzionante. Sebbene l'host possa accedere all'immagine Snapshot, non può leggerla o scriverci direttamente.



 a| 
Volume base
 a| 
È possibile visualizzare il volume di base associato al volume Snapshot. Un volume di base è la fonte da cui viene creata un'immagine Snapshot. Può essere un volume thick o con thin provisioning e in genere viene assegnato a un host. Il volume di base può risiedere in un gruppo di volumi o in un disk pool.



 a| 
Gruppo Snapshot
 a| 
È possibile visualizzare il gruppo di snapshot associato al volume di snapshot. Un gruppo di snapshot è una raccolta di immagini snapshot provenienti da un singolo volume di base.

|===

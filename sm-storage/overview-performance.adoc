:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La pagina Prestazioni offre semplici modi per monitorare le prestazioni del tuo storage array.



[[what-can-i-learn-from-performance-data]]
== Cosa posso imparare dai dati sulle prestazioni?

I grafici e le tabelle delle prestazioni mostrano i dati sulle prestazioni quasi in real-time, il che ti aiuta a determinare se un array di storage sta riscontrando problemi. Puoi anche salvare i dati sulle prestazioni per costruire una vista storica di un array di storage e identificare quando è iniziato un problema o cosa lo ha causato.

Per saperne di più:

* link:performance-graphs-guidelines.html["Grafici delle prestazioni e linee guida"]
* link:performance-terminology.html["Termini di performance"]

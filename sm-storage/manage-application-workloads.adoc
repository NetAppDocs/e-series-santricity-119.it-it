= Gestisci applicazioni e carichi di lavoro in SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile gestire applicazioni e carichi di lavoro per visualizzare tutti i volumi esistenti sull'array di storage raggruppati per nome del carico di lavoro e tipo di applicazione. È inoltre possibile aggiungere volumi a un carico di lavoro esistente o nuovo, modificare le impostazioni di un carico di lavoro esistente e creare nuovi volumi e carichi di lavoro.

= Scopri la funzionalità Remote Storage in SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se disponi della funzionalità Remote Storage, puoi importare dati da un sistema storage remoto nel tuo storage array.



== Che cos'è la funzione Remote Storage?

La funzione _Remote Storage_ consente di importare dati da un sistema storage remoto a un sistema storage E-Series locale. Il sistema remoto può essere un altro sistema E-Series o un sistema di un altro fornitore. Questa funzione è utile quando si desidera semplificare la migrazione dei dati riducendo al minimo i tempi di inattività, ad esempio durante gli aggiornamenti delle apparecchiature.


NOTE: Per utilizzare lo storage remoto, questa funzione deve essere abilitata nel Submodel ID (SMID).

== Come faccio a importare i dati con questa funzione?

Tramite la procedura guidata Remote Storage, è possibile associare un dispositivo di storage (la fonte per l'importazione dei dati) a un volume di destinazione sul sistema E-Series. Questa procedura guidata è disponibile dal menu:Storage[Remote storage].

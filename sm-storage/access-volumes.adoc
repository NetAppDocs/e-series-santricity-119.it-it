= Accedere ai volumi in SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Un volume di accesso è un volume configurato in fabbrica sull'array di storage che viene utilizzato per la comunicazione con l'array di storage e l'host tramite la connessione I/O dell'host. Il volume di accesso richiede un Logical Unit Number (LUN).

Il volume di accesso viene utilizzato nel seguente caso:

* *Gestione in banda* -- Il volume di accesso viene utilizzato per una connessione in banda per gestire l'array di storage. Questo può essere fatto solo se si gestisce l'array di storage con la command line interface (CLI).
+
[NOTE]
====
La gestione in banda tramite il volume Access non è disponibile per i sistemi storage E4000, EF600/EF600C o EF300/EF300C.

====


Un volume di accesso viene creato automaticamente la prima volta che si assegna un volume a un host. Ad esempio, se si assegnano Volume_1 e Volume_2 a un host, quando si visualizzano i risultati di tale assegnazione, si vedono tre volumi (Volume_1, Volume_2 e Access).

Se non si creano automaticamente host o non si gestisce un array di storage in-band tramite CLI, non è necessario il volume di accesso ed è possibile liberare la LUN eliminando il volume di accesso. Questa operazione rimuove l'assegnazione volume-LUN e tutte le connessioni di gestione in-band all'host.
